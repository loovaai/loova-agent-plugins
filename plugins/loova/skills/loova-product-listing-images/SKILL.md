# Product Listing Images

Build a listing image set in which every image answers a distinct buying question. Maintain one confirmed SKU, a coherent color system, and a clear text hierarchy.

## Establish the facts

Read product photos, SKU information, destination, and supplied dimensions, materials, accessories, functions, and evidence. Separate supplied facts, directly visible facts, and unknowns. Never infer dimensions, certifications, performance, sales, or comparison claims from appearance.

If no destination is specified, use a general listing layout without claiming platform compliance. Consult current official requirements only when the destination makes them relevant. Keep explicit output counts. For an unspecified full set, propose a useful mix of main, feature, detail, lifestyle, and specification images without inventing benefits to fill slots.

## Workflow

1. Assign each image an information goal, supporting fact, required angle, and exact copy. Separate main-image requirements from promotional secondary-image conventions.
2. Set consistent product placement, headings, backgrounds, annotations, and whitespace. Preserve real packaging copy where possible; compose additional text separately when the tools support it.
3. Generate the required product scenes and assemble accurate copy and specifications. Read [Loova execution](references/execution.md) before media operations. If text layout or a required module is unsupported, deliver completed assets and identify the remaining composition step.
4. Check the actual reading size, especially on mobile. Verify every number, unit, annotation endpoint, and product feature.
5. Keep sets within the user's chosen colorways and variants. Additional colorways are acceptable when requested; identify simulated options rather than presenting unverified variants as products available for sale.

## Quality and delivery

Check consistent color, accessories, quantities, ports, and product version across the set. Props must not appear to be included accessories. Use real detail references for close-ups; label explanatory diagrams as diagrams rather than claiming they reveal hidden construction. Resolve conflicting facts instead of choosing a convenient value.

Fix a text layout defect locally; fix product identity before rebuilding a set. Deliver in the requested order with the actual files and a short image map. State missing facts or unfinished modules. A completed image set does not imply marketplace approval.
