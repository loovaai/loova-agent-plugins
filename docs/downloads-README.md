# Loova Creative Skills

English creative workflows for product images and videos. See `catalog.json` for this release's version, ten skill entries and individual download paths.

Extract the full bundle or a single-skill ZIP. Install the entire directory containing `SKILL.md`, preserving `agents/openai.yaml` and `references/execution.md`, through your agent's supported skill-loading flow. Copying a file into a chat does not necessarily install a persistent skill.

Connect and authorize Loova separately at `https://mcp.loova.ai/mcp`. Skills do not grant model permissions or spending approval. For plugin installation that bundles MCP configuration, see https://github.com/loovaai/loova-agent-plugins .

Ask for example: “Use loova-product-photoshoot to create a studio photo of this product. Show the model and price before generating.” Or: “Use loova-viral-video-clone to recreate this ad for my product.” Preserve the user's requested output language and locked copy; English instructions do not require English media.

Local files use the supported upload session or browser upload fallback. Motion imitation and video cloning use Loova's dedicated tools. Available models, controls, prices and Unlimited eligibility come from the live service. Unsupported editing, assembly or exact preservation requirements must be disclosed.

This release uses `loova-viral-video-clone` in place of the earlier `loova-viral-video-remake`. If you manually installed the old skill, back it up outside the agent's skill search directory and remove that old installation after installing the replacement. Do not keep both enabled. Other names are unchanged.

Catalog download paths resolve relative to the website release directory. The full bundle does not embed the individual download ZIPs. Inspect actual results; installation or successful job status does not prove visual quality.
